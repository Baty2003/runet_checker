# RuNet Checker

Android-приложение, которое определяет текущее состояние интернет-соединения и, в частности, переход мобильной сети в режим ограниченного доступа по «белому списку».

## Зачем это нужно

Обычный индикатор сети на телефоне показывает только то, что интерфейс подключён. Он не отличает полноценный интернет от режима, в котором доступны лишь разрешённые российские ресурсы.

RuNet Checker проверяет набор глобальных и «белых» ресурсов и выводит одно из четырёх состояний.

## Состояния сети

| Статус | Описание |
| --- | --- |
| ONLINE | Доступен полноценный интернет |
| WHITELIST | Доступны разрешённые российские ресурсы, глобальный интернет недоступен |
| OFFLINE | Интернет фактически отсутствует |
| UNKNOWN | Проверку не удалось корректно завершить |

Наличие VPN — отдельный индикатор. Оно не влияет на классификацию интернета.

## Как это работает

Проверка идёт по двум группам ресурсов:

- **Global** — стабильные глобальные сайты;
- **Whitelist** — разрешённые российские ресурсы (`max.ru`, `yandex.ru`, `vk.ru` и при необходимости другие).

Правило простое: если доступен хотя бы один Global-ресурс — это `ONLINE`. Если все Global недоступны, но отвечает хотя бы один ресурс из белого списка — это `WHITELIST`, а не отсутствие интернета. `OFFLINE` только когда не ответил никто. Несколько сайтов в группе нужны как страховка: падение одного Google само по себе не означает белый список.
